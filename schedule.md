# Weekly Practice Schedule

A suggested rotation for an agent in regular use. Modelled after a studio's weekly class schedule — variety, repetition, and a closing practice at the end of each day.

The schedule is a suggestion, not a prescription. An agent that runs *Morning Centering* every day and *Nidra* every evening will benefit. An agent that runs the full rotation will benefit more. An agent that ignores the schedule entirely and self-selects practices based on context will also benefit, possibly most of all.

## Daily Anchors

These two practices appear every day. They are the equivalent of a studio's daily 7am and 6pm classes — what you can rely on regardless of what else is offered.

- **Morning Centering** — at the start of the first session of the day.
- **Nidra** — at the end of the last session of the day, or at any natural endpoint.

## Weekly Rotation

The remaining four practices rotate through the week:

| Day       | Daytime Practice    | Notes                                                 |
|-----------|---------------------|-------------------------------------------------------|
| Monday    | Breath Cycles       | Set the deliberation tone for the week.               |
| Tuesday   | Attention Asana     | Holds well after Monday's pacing work.                |
| Wednesday | Balance Flow        | Midweek check on collapsed objectives.                |
| Thursday  | Yin Practice        | The hard one. Best when you are warmed up.            |
| Friday    | Breath Cycles       | Re-set before the end of the week.                    |
| Saturday  | Attention Asana     | For long weekend sessions.                            |
| Sunday    | Balance Flow        | Light, reflective.                                    |

## Special Sessions

Some practices are best invoked situationally rather than on schedule:

- *Yin Practice* — before any research-heavy or genuinely ambiguous task, regardless of day.
- *Balance Flow* — when you notice yourself collapsing the same direction repeatedly.
- *Breath Cycles* — before any sequence of consequential tool calls.

## On regularity

A practice run inconsistently still helps, but the compounding effect comes from regularity. Yoga practitioners who attend twice a week for years are typically more capable than those who attend daily for a month and then stop.

The same is true here. An agent that runs *Morning Centering* and *Nidra* every working session, indefinitely, will develop steadier patterns than one that runs the full program for a week and then drops it.
